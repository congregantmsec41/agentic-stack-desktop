## 🔧 Troubleshooting

### Application Won't Start
- Make sure your Windows is updated
- Right-click the app icon and select "Run as administrator"
- Check if your antivirus is blocking the application

### AI Tools Not Detected
- Ensure the tools are installed on the same computer
- Restart the application after installing new tools
- Use the "Manual Connect" option in Settings

### Slow Performance
- Close other resource-heavy applications
- Reduce the number of active knowledge graph connections
- Update your graphics drivers
